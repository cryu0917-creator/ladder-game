# 🎯 인터랙티브 사다리 타기 게임 (Ghost Leg Game)

직관적이고 미려한 디자인의 웹 기반 인터랙티브 사다리 타기 게임입니다.

![Preview](index.html)

## ✨ 주요 기능
- **동적 참가자 및 결과 설정**: 참가자 수와 당첨/벌칙 항목을 자유롭게 추가 및 수정
- **사다리 자동/커스텀 생성**: 랜덤 가로줄 배치 및 경로 시각화
- **실시간 애니메이션**: 선택한 참가자의 사다리 이동 경로를 부드러운 애니메이션으로 추적
- **모던 UI/UX**: Pretendard 폰트 기반 다크 테마 및 반응형 레이아웃 지원
- **단일 파일 실행**: 별도의 빌드 과정 없이 `index.html` 더블 클릭만으로 브라우저에서 즉시 실행

## 🚀 빠른 시작
1. 저장소를 클론합니다:
   ```bash
   git clone https://github.com/<your-username>/ladder-game.git
   ```
2. `index.html` 파일을 크롬이나 엣지 등 웹 브라우저로 엽니다.

## 🌐 GitHub Pages 배포 방법
1. 저장소의 **Settings** > **Pages**로 이동합니다.
2. **Branch**를 `main`으로 설정하고 **Save**를 클릭합니다.
3. 몇 분 후 제공되는 GitHub Pages URL을 통해 웹상에서 누구나 사다리 게임을 즐길 수 있습니다.
